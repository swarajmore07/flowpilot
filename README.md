
# 🚀 FlowPilot AI

### AI-Powered Supply Chain Command Center

FlowPilot AI is a modern, AI-powered supply chain management platform designed to help businesses monitor inventory, manage suppliers, analyze operations, and make smarter business decisions through intelligent insights.

Built with a modern dashboard interface, FlowPilot AI brings essential supply chain operations into one centralized command center.

## 📌 Overview

Managing supply chain operations often requires working with multiple systems for inventory, suppliers, analytics, and operational monitoring.

**FlowPilot AI** aims to simplify this process by providing a centralized dashboard that helps users:

- Monitor inventory and stock levels
- Manage supplier information
- Track supply chain operations
- Analyze business performance
- View important alerts and insights
- Make data-driven operational decisions

The platform is designed with a clean, professional interface inspired by modern enterprise platforms.

## ⚙️ Getting Started

Follow these steps to run FlowPilot AI locally.

### 1. Clone the Repository

```bash
git clone https://github.com/swarajmore07/flowpilot.git
```

### 2. Navigate to the Project

```bash
cd flowpilot
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open the Application

Visit:

```text
http://localhost:3000
```

## 🔐 Environment Variables

Currently, the project does not require a local `.env` file if no environment-dependent services are configured.

If environment variables are introduced in the future:

1. Create a `.env.local` file.
2. Add the required configuration values.
3. Add the same variables in the Vercel project settings.
4. Never commit sensitive credentials to GitHub.

Example:

```env
NEXT_PUBLIC_API_URL=your_api_url
```

> Use only the environment variables actually required by your application.

## 🚀 Deployment

FlowPilot AI can be deployed using **Vercel**.

### Deploy with Vercel

1. Push the project to GitHub.
2. Open [Vercel](https://vercel.com).
3. Import the GitHub repository.
4. Select the `flowpilot` repository.
5. Configure environment variables if required.
6. Click **Deploy**.

After deployment, Vercel will provide a live website URL.
